# Aide-mémoire du référent

**Votre rôle** : rien n'arrive aux élèves sans votre validation. Les agents (des intelligences artificielles) préparent des brouillons ; vous lisez, puis vous validez, rejetez ou demandez une révision.

## Pour chaque chapitre du pilote, dans cet ordre

1. **Programme du chapitre** : titre, sous-thèmes, volume horaire, par rapport au programme officiel. → Valider, ou Rejeter avec un commentaire.
2. **Liens de prérequis** : « ce chapitre demande celui-là ». → Valider, ou Rejeter avec une remarque.
3. **Script de cours** : demandez le brouillon, lisez-le en entier, vérifiez chaque **[À VÉRIFIER]**. → Valider, ou Demander une révision.
4. **Quiz** : demandez le brouillon ; vérifiez chaque question, la bonne réponse et l'explication. → Cochez la case, puis Valider.
5. **Vidéo** (si un fournisseur est choisi) : regardez-la **en entier**, avec les sous-titres. → Valider, puis **Publier** (second geste, distinct).

La plateforme indique pour chaque chapitre la **prochaine action**, en tête de votre espace.

## Toujours

- **Lire avant de valider.** Chaque validation porte votre prénom, la version, l'empreinte du contenu et la date.
- **Un commentaire de rejet dit ce qu'il faut corriger** : l'agent s'en sert pour la version suivante.
- **En cas de doute, rejeter** (ou demander une révision) plutôt que valider.

## Jamais

- Valider un contenu que vous n'avez pas lu en entier.
- Écrire dans un commentaire un nom d'élève, un numéro de téléphone ou une information personnelle.
- Transmettre votre code d'invitation, ou un code de connexion reçu par SMS, à qui que ce soit.
- Laisser passer une erreur de contenu sensible (santé, reproduction, histoire récente) : rejetez et prévenez le propriétaire.
