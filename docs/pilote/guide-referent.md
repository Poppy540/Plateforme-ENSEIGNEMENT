# Guide de l'enseignant-référent

**Pour qui** : l'enseignant qui valide les contenus d'une famille de matières (par exemple les Mathématiques).
**Statut** : rédigé par Claude Code (Jalon 6, étape 6), à relire par le propriétaire avec le premier référent.

## 1. Votre rôle, en une phrase

Rien n'arrive aux élèves sans votre validation : chapitres, liens entre chapitres, scripts de cours, quiz et vidéos. Les agents (des intelligences artificielles) préparent des **brouillons** ; c'est vous qui lisez, corrigez par une demande de révision, validez ou rejetez.

## 2. Accéder à votre espace

1. Le propriétaire vous transmet un **code d'invitation** par un canal sûr. Il est valable quelques jours.
2. Connectez-vous sur le site avec votre numéro de téléphone (code reçu par SMS), puis ouvrez **« Activer votre accès avec votre code »**.
3. Saisissez votre prénom (ou un pseudonyme) et le code. Vous arrivez sur **l'espace référent**.

Votre connexion dure **7 jours**. Ensuite, redemandez un code. Téléphone perdu ? Ouvrez **Mes données**, puis « Me déconnecter de tous mes appareils ».

## 3. Ce que vous voyez, et ce que vous ne voyez pas

- Vous voyez les contenus de **vos familles** de matières, toutes classes et séries confondues.
- Vous ne voyez **aucun élève** : ni nom, ni messages, ni signalement. Vous voyez seulement des statistiques de quiz anonymes, à partir de 5 tentatives. Les signalements et la détresse sont traités par l'administration et l'équipe de veille.
- Vous ne pouvez rien modifier directement. Toute correction passe par une **nouvelle version**, que vous relisez à son tour.

## 4. Valider, dans cet ordre

| Étape | Où | Ce que vous faites | Attention |
|---|---|---|---|
| 1. Chapitres | Espace référent → un chapitre | Vérifier le titre et les sous-thèmes par rapport au programme officiel, puis **Valider la version** ou **Rejeter** (commentaire obligatoire) | Si le chapitre change pendant votre lecture, la validation est refusée : relisez la nouvelle version |
| 2. Liens de prérequis | « Liens de prérequis à valider », ou la page d'un chapitre | Pour chaque lien proposé (« ce chapitre demande celui-là »), **Valider le lien** ou **Rejeter** (avec remarque) | Un lien vers une **autre famille** (par exemple Physique-Chimie ← Mathématiques) est décidé par le référent du chapitre qui en dépend : vous lisez le chapitre visé sans pouvoir l'ouvrir |
| 3. Scripts de cours | Page d'un chapitre validé → **Générer un brouillon de script** (durée, consigne facultative) | Lire tout le script : explication, exemples, erreurs fréquentes, travaux pratiques, glossaire. Vérifier les **points [À VÉRIFIER]** et les **exemples locaux à valider**. Puis valider, ou **Demander une révision** | Le script validé devient aussi la **leçon écrite** que lisent les élèves, y compris sans vidéo et hors connexion |
| 4. Quiz | Page d'un chapitre validé → **Générer un quiz brouillon** | Vérifier chaque question, la bonne réponse et l'explication. Cocher la case de vérification, puis valider | Les élèves passent le quiz une seule fois. Une contestation répétée vous revient comme signalement d'erreur de contenu |
| 5. Vidéos | Page d'un script validé → production vidéo, puis page de la vidéo | Regarder **toute** la vidéo avec les sous-titres, cocher la case de vérification, valider. **Publier** est un second geste, distinct | Une vidéo n'est produite qu'à partir d'un script validé et inchangé |

## 5. Les autres outils

- **Conformité au programme officiel** : déposez un document officiel (texte ou PDF de 10 Mo au plus), puis **Analyser**. L'agent Conformité rédige un **rapport d'écart**, qui reste une recommandation : rien ne change sans vous. Seul le propriétaire peut supprimer un document.
- **Coordinateur de famille** : **Lancer une revue de cohérence** sur votre famille (notations, progression d'une classe à l'autre, liens manquants). Il propose des brouillons : glossaire, charte, plan de production. Vous les acceptez ou les écartez (remarque obligatoire pour écarter).

## 6. Règles à garder en tête

- **Ne validez jamais sans avoir lu.** Chaque validation est tracée : votre prénom, la version, l'empreinte du contenu et la date.
- Un contenu douteux se **rejette** avec un commentaire clair : l'agent s'en sert pour la version suivante.
- Ne mettez dans un commentaire ni nom d'élève, ni numéro, ni information personnelle.
- Pour tout doute sur un contenu sensible (santé, reproduction, histoire récente) ou sur un problème de sécurité, prévenez le propriétaire.

## 7. Vos données

**Mes données**, depuis l'espace référent, permet de télécharger tout ce que la plateforme garde sur vous : familles, décisions de validation, documents déposés. Votre compte porte des validations tracées : sa suppression se fait avec le propriétaire.
