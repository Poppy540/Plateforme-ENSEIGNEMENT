# 0001 — Tout ce qui dépend du pays vit dans un pack pays

- **Date** : 2026-10-04 · **Statut** : validée (prompt maître §1)
- **Décision** : classes, séries, examens, programmes, coefficients, langue, calendrier, contexte local, paiement et cadre légal sont des données dans `referentiels/<pays>/`. Le code n'en contient aucune, ni le décompte d'unités.
- **Conséquence** : un code interne neutre relie les référentiels ; ajouter un pays ne demande pas de modifier le code.
