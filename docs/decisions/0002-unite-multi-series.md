# 0002 — Une unité peut couvrir plusieurs séries (écart E2)

- **Date** : 2026-10-04 · **Statut** : validée par le propriétaire
- **Contexte** : la matrice du cadrage compte « Première A1/A2 » comme une seule unité par matière, alors qu'une unité est définie comme (niveau, série, matière).
- **Décision** : une unité est (référentiel, niveau, **ensemble de séries**, matière). L'ensemble est vide au collège et en Seconde.
- **Conséquence** : le Gabon compte bien 67 unités (sinon 75). Code d'unité : `ga-1re-a-francais` pour A1+A2.
