# 0108 — Plan du Jalon 21 : programme du pilote complet

- **Date** : 2026-11-03 · **Statut** : validé par le propriétaire

## Contexte

Le programme de Mathématiques 3e du pack contient 7 titres de chapitres, issus d'une base francophone générique (cadrage). Il n'a ni sous-thèmes, ni objectifs, ni volumes horaires, ni liens de prérequis par chapitre. Les captures du kit du référent (Jalon 19) le montrent : « Aucun sous-thème indiqué ». Le référent devrait tout reconstruire avant de valider le premier chapitre.

## Décision

Plan `docs/plans/jalon-21.md` :

1. sources publiques recherchées et consignées, avec leur fiabilité ;
2. programme complété champ par champ, chaque donnée renvoyant à sa source, le pack restant « à valider » ;
3. fiche de relecture par chapitre pour le référent ;
4. passages réels dès la clé ;
5. bilan.

Rien n'est inventé : ce qui n'a pas de source reste vide et signalé.

Écartés pour ce jalon : la preuve d'exportabilité, une nouvelle matière, la pause.

## Conséquences

- La validation reste au référent ; rien n'est montré aux élèves avant elle.
- Si le programme officiel n'est pas public, il faudra l'obtenir par l'établissement ou le référent : le plan le signale, sans le remplacer par une supposition.
