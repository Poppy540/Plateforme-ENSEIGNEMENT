# 0058 — Plan du Jalon 8 : débloquer le réel

- **Date** : 2026-10-22 · **Statut** : validé par le propriétaire

## Contexte

Les Jalons 5 à 7 ont préparé la plateforme pour le pilote en simulation. Les 12 conditions du pilote attendent surtout le propriétaire et des personnes extérieures : juriste, référents, fournisseurs, hébergement, clé API. Deux choses manquent pour faciliter ces démarches :
- aucun document ne réunit pour le juriste ce que la plateforme fait des données ;
- aucun guide ne dit au propriétaire, dans l'ordre, quoi faire.

Par ailleurs, la tenue en charge n'a jamais été mesurée, et les agents n'ont aucun test propre au Français.

## Décision

Plan `docs/plans/jalon-8.md` :
- dossier pour le juriste et guide de mise en route d'abord ;
- puis un essai de tenue à 200 élèves simultanés sur la base locale ;
- puis des tests des agents pour le Français ;
- passages réels dès la clé : mini-essais, puis séries complètes, chaque coût accepté séparément.

Aucun nouveau contenu ; aucune nouvelle dépendance.

## Conséquences

- Rien n'est déployé ni souscrit.
- Les documents sont des propositions de Claude Code : le dossier pour le juriste ne remplace pas son avis.
- La tenue en charge mesurée sur la base locale donne un ordre de grandeur, pas une garantie pour l'hébergement réel.
