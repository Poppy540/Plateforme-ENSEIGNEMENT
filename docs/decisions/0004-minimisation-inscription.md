# 0004 — Données collectées à l'inscription (écart E4)

- **Date** : 2026-10-04 · **Statut** : validée par le propriétaire
- **Contexte** : le cadrage demande nom, prénom et établissement ; le prompt maître impose la minimisation.
- **Décision** : prénom ou pseudonyme, classe, série (si besoin), téléphone ou email, contact du parent ou tuteur pour un mineur. Établissement **facultatif**. **Pas de nom de famille.**
- **Conséquence** : journaux pseudonymisés ; export, suppression et durée de conservation configurables.
