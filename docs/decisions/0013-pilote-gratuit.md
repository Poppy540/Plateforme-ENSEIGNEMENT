# 0013 — Pilote gratuit

- **Date** : 2026-10-04 · **Statut** : validée par le propriétaire
- **Décision** : le pilote est **gratuit** pour les élèves. Aucun paiement, abonnement ni Mobile Money n'est construit pour les jalons 1 à 3.
