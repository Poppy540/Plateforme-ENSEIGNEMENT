# Captures du Jalon 18

La lecture sans réseau étendue (décision D14 b, ADR 0101), sur téléphone simulé, avec des données **fictives**. Un élève de 5e a ouvert « Mes cours », les chapitres de Mathématiques, son plan de révision et la correction de son quiz ; puis le réseau est coupé. Rien n'est effacé.

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-18.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-18`.
