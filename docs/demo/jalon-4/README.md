# Captures du Jalon 4

Parcours sur téléphone simulé, données fictives, modèles et messagerie **simulés** : les textes « (simulé) » montrent le parcours, pas la qualité réelle des agents. Le pays « Z » est un pays **fictif** de test (ADR 0041).

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-4.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-4`.
