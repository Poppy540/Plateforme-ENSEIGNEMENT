# Captures du Jalon 13

Une semaine de pilote **fictive**, sur téléphone simulé : 8 élèves fictifs (6 actifs dans la semaine), une détresse fictive restée 13 h sans prise en charge, l'accès des élèves fermé puis rouvert, le journal et le rapport de la semaine. Aucun élève réel.

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-13.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-13`.
