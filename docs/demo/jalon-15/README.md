# Captures du Jalon 15

Le tableau de bord du pilote dans ses quatre phases, sur téléphone simulé, avec des données **fictives** : 6 élèves fictifs, un chapitre du pilote. On y voit aussi la liste « Ce qui vous attend » et le rapport de fin en cartes. Pour la démonstration, les phases sont posées directement en base (dates, gestes de clôture) ; rien n'est effacé.

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-15.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-15`.
