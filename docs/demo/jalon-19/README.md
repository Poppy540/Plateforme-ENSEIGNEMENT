# Captures du Jalon 19

Une journée d'ouverture en petit, sur téléphone simulé, avec des données **fictives** : une classe de 6, un chapitre et son quiz validés, 6 élèves, un 7e refusé. Les captures du kit du référent sont dans [`docs/pilote/kit-referent/captures`](../../pilote/kit-referent/captures).

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-19.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-19`.
