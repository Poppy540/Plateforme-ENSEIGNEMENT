# Captures du Jalon 22

Le pays **fictif** Z, à côté du pilote, sur téléphone simulé : ses « Années » et ses « options » viennent de son pack, sans une ligne de code propre à ce pays (ADR 0111 à 0114). Données fictives : un administrateur, un enseignant, trois élèves, une classe « Année 2 A (pays Z, démonstration) ». Rien n'est effacé.

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-22.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-22`.
