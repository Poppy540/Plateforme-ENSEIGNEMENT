# Captures du Jalon 6

Parcours sur téléphone simulé, avec des données fictives, des modèles et une messagerie **simulés** ; le pays « Z » est fictif. Les textes de leçon et de questionnaire sont inventés pour la démonstration.

Régénérables avec `cd application && pnpm demo:captures tests/demo/jalon-6.spec.ts`, puis `bash scripts/compresser-captures.sh ../docs/demo/jalon-6`.
