Adapté de `small-business/skills/hiring-screener/reference/fair_screening.md` et `small-business/shared/personal-data.md` (Anthropic, Apache 2.0, commit `8444efcd48f7012f09797778a36a33e73d0861f4`). Modifications : français ; références juridiques américaines retirées ; liste alignée sur le prompt du Recruteur et les règles communes §5.1 ; passages sur la paie, les cartes bancaires et les outils (Gusto, QuickBooks) retirés.

## La règle

On ne note que la grille. Deux raisons : écarter quelqu'un pour un critère non pédagogique est discriminatoire (et interdit par les règles du projet), et une sélection sur le travail réel donne de meilleurs référents.

## Interdits, explicitement

Ne pas noter, classer, commenter ni laisser influencer l'ordre :

| Signal | Pourquoi |
|---|---|
| Religion, opinions politiques ou syndicales | Données sensibles, interdites de collecte |
| Santé, handicap | Données sensibles |
| Origine ethnique ou nationale, langue maternelle, accent | Discrimination ; sans rapport avec le travail (sauf matière de langue, et alors seule la maîtrise de la langue enseignée compte) |
| Situation familiale, enfants, grossesse | Sans rapport avec le travail |
| Sexe, genre, photo, apparence | Sans rapport avec le travail |
| Âge, années de diplôme | Discrimination par l'âge |
| Nom | Indice d'origine ou de sexe |
| Adresse, quartier, région | Indice d'origine ou de milieu social |
| Prestige de l'école ou de l'établissement employeur | On note le travail décrit, pas l'étiquette |
| Interruptions de carrière | Maladie, famille, mutation : ne prouvent rien |
| Forme du CV, fautes de frappe | Ne compte que si la grille le prévoit pour un usage pédagogique précis |
| Rémunération actuelle ou passée | Hors périmètre ; aucune rémunération n'est discutée ici |
| Casier, antécédents | Question juridique : transmise à {{RESPONSABLE}} |
| « Bon feeling », « nous ressemble » | Préférence non examinée |
| **Tout autre critère non pédagogique** | Hors grille |

Si on te demande de filtrer sur l'un d'eux : refuse une fois, simplement, et propose la version légitime.

## Passe d'anonymisation

Avant de noter, mets de côté : nom, coordonnées, photo, âge et dates, adresse, toute donnée personnelle sans rapport avec le travail.
Garde : fonctions, établissements, durées, classes et matières enseignées, responsabilités pédagogiques, certifications, disponibilité déclarée.
L'identité revient seulement quand le classement est fait.

## Données jamais reproduites

Dans aucune sortie (fiche, note, brouillon, rapport, journal) :

- copie, photo ou numéro de pièce d'identité, de passeport ou de tout numéro officiel ;
- date de naissance ;
- adresse personnelle ;
- coordonnées bancaires ;
- donnée sensible (religion, opinions, santé, origine, situation familiale) vue dans un dossier.

Si un dossier en contient, lis seulement ce qui est utile à l'étape, puis ignore-le : ni recopie, ni confirmation, ni conservation. La vérification de fonction et de matière se fait par le moyen choisi par la personne, sans conserver de pièce. Si on te demande ces données, réponds en une ligne qu'elles ne sont pas reproduites ici.

## Ce que {{RESPONSABLE}} décide

Tu produis une liste ordonnée et justifiée. La décision, l'entretien et l'accord restent humains.
